# 민기사 크루 기능 목록

## 터미널 선택

- 상단 탭: T1(제1터미널) / T2(제2터미널) / 김포(GMP) 전환
- 탭 전환 시 해당 터미널 데이터로 전체 화면 갱신

---

## 인천공항 — 운항편 탭 (기본 탭)

### 시간 블록 버튼
- 3시간 단위 블록 (00-03, 03-06, ..., 21-24) — 가로 스크롤
- **앱 초기 진입 시**: 현재 KST 시각이 포함된 블록 자동 선택
- **블록 버튼 클릭 시**: 목록 최상단으로 스크롤 이동 (timeCard bottom 기준 viewport top 정렬)
- **현재 블록 스타일**: 점선 테두리 + 초록 강조
- **00~05 블록 익일 처리**: KST 06시 이후에는 해당 블록을 다음날로 표시

### "지금" 구분선
- 현재 시각이 포함된 블록이 선택된 경우에만 표시
- 현재 시각 기준 첫 번째 미래 항공편 바로 위에 "지금 | 이후 도착편" 구분선 삽입
- 블록 진입 시 구분선 위치로 자동 스크롤

### 기준 토글 (도착/출구)
- **도착기준(착)**: 항공기 활주로 착륙 시각 기준 정렬 (기본값)
- **출구기준(출)**: 입국장 출구 예상 도착 시각 기준 정렬

### 장거리 필터
- "장거리" 버튼: 비행시간 7시간 이상 편만 표시 (IATA 공항 코드 기반 비행시간 테이블)
- 토글 시 목록 최상단으로 스크롤 이동

### 항공사 필터
- 우측 필터 아이콘 클릭 → 하단 모달 슬라이드업
- 전체 선택 / 전체 해제 / 대형항공사만 선택 버튼
- 항공사명 검색 (실시간 필터링)
- 체크박스로 개별 항공사 선택/해제

### 운항편 목록 행 구성
- **왼쪽**: 착륙 시각(착) + 출구 예상 시각(출), 지연 시 취소선+주황 대체 시각
- **가운데**: 비행시간 배지(국/단/중/장) + 출발지 + 편명 + 항공사명
- **오른쪽**: 상태 배지 + 게이트 번호 + 외국인 대기인원(출구기준 시)

### 코드쉐어 편명 묶음
- 같은 스케줄+출발지의 편명은 하나의 행으로 묶어 표시
- 추가 편명은 `+N` 버튼으로 펼치기/접기

### 상태 배지
- **지연(주황)**: 예정 시각보다 늦게 착륙
- **단축(파랑)**: 예정 시각보다 일찍 착륙
- **심야(주황 배경)**: 대중교통 운행 없는 시간대 (isNoTransport)

### 기타 배지
- **익일**: 오늘이 아닌 다음날 도착편
- **비행시간 배지**: 출발지 공항 코드 기준 — `국` (국제 단거리), `단` (~3h), `중` (~6h), `장` (7h+)

### 혼잡도 정보 (입국장 현황 API)
- 게이트 번호 표시 (입국장 혼잡도 데이터 있을 때)
- 출구기준 선택 시 외국인 대기인원 표시

### 빈 상태 구분
- **API 오류**: "데이터를 불러올 수 없습니다"
- **데이터 없음**: "이 시간대 운항편 없음"

### 레이아웃 불변 조건
- 컬럼 헤더(도착·출구 | 출발지·편명 | 상태)와 목록(또는 빈 상태 메시지) 사이에 빈 공간이 없어야 함 — spacer는 fixed 헤더 높이만큼만 사용

## 인천공항 — 현황 탭

### 현재 입국 대기 현황
- 현재 입국장 외국인 대기인원 / 전체 대기인원
- 피크 예상 시간대 표시

### 승객 예고 차트
- 시간대별 예상 승객 수 (막대 차트)
- 오늘 + 내일 데이터

### 주간 예측
- 7일간 요일별 예상 운항편 수

### 택시 승강장
- T1 / T2 택시 승강장 현황 (대기 대수, 혼잡도)
- 데이터 없으면 0대로 표시 (섹션 항상 표시)

---

## 김포공항 탭

- **국내도착 / 국제도착** 탭 전환
- 시간 블록 선택 (현재 시각 포함 블록 자동 선택)
- 현재 시각 기준 "지금" 행 구분선 표시 후 스크롤
- 편명 / 항공사 / 출발지 / 착륙 시각 / 지연 여부 표시
- 클라이언트 모듈 캐시 5분 — 탭 재방문 시 fetch 없이 즉시 표시, 5분 경과 후 재요청

---

## 날씨 위젯 (인천공항 T1/T2만)

- 상단 우측 날씨 배지: 현재 기온 + 날씨 아이콘
- 클릭 시 날씨 모달 오픈
  - 주간 탭: 7일간 날씨 예보
  - 시간별 탭: 24시간 기온/날씨

## 시스템 / 공통

| 기능 | 설명 |
|------|------|
| 데이터 갱신 | 서버 5분 캐시, 페이지 접속마다 API 자동 호출 |
| 풀투리프레시 차단 | `overscroll-behavior: none` (body) + `overscroll-contain` (스크롤 컨테이너) |
| 자동 오류 배너 | 인천공항 운항편 API가 실제로 실패(`flightFetchError=true`)한 경우에만 고정 헤더(T1/T2/GMP 탭 바로 아래) 하단에 amber 배너 표시 — 모든 탭(운항편·입국현황·김포)에서 보임 |
| 김포공항 출처 표기 | 데이터 정상 로드 또는 오류 시 모두 "한국공항공사 실시간 운항정보 · 5분 갱신" 표시 (로딩 중만 숨김) |
| PWA | iOS/Android 홈화면 추가 설치 지원 |
| Capacitor 앱 | Android 네이티브 앱 (UA: `MinGisaCrewApp`) |
| 앱 전용 모드 | `APP_LAUNCH_MODE=true` 시 웹 접근자를 앱 다운로드 페이지로 리다이렉트 |
| Vercel Analytics | 페이지뷰 및 사용자 행동 추적 |

## 개발 편의 env var (.env.local 전용)

| 변수 | 값 | 설명 |
|------|-----|------|
| `USE_MOCK` | `true` | 인천공항 + 김포공항 API를 모두 mock data로 대체 (서버 재시작 필요) |
| `MOCK_FLIGHT_ERROR` | `true` | `USE_MOCK=true` 상태에서 운항편 API만 강제 실패 → 오류 배너 + 빈 상태 UI 테스트용 |
